## 1.0.0

## 核心：治病前先要钱

```
医疗算出要花 2400
  → 上报终端（Amo）
  → 终端下发金融扣款 + 数据记账
  → 扣到了？执行治疗 : 不治疗，病情继续加重
```

医疗自己**不碰钱**。它只负责「这病怎么治、多少钱、医保报多少」，钱由终端统一调度——
这样每一笔账她都知情，不会出现"医疗偷偷划钱、Amo 不知道"的情况。

## 病情分级

| 病 | 严重度 | 治疗费 | 医保 | 不治会变成 |
|---|---|---|---|---|
| 过度疲劳 | 轻 | 0（休息） | — | — |
| 轻微不适 | 轻 | 30–80 | 门诊 | 感冒 |
| 感冒 | 轻 | 150–300 | 门诊 | 发烧 |
| 发烧 | 中 | 300–600 | 门诊 | 肠胃炎 |
| 肠胃炎 | 中 | 800–1500 | 门诊 | 阑尾炎 |
| 阑尾炎 | 重 | 8000–15000 | 住院 | — |
| 骨折 | 重 | 6000–20000 | 住院 | — |

## 医保

- 门诊：起付 300，报 70%；
- 住院：起付 1500，报 85%；
- 大病：超过 2 万的部分再报 60%；
- 年度上限 30 万。

所以阑尾炎 12000 的实际自付是 **3075**，不是 12000。这就是「有医保的人不会因为一场手术破产」的真实感。

## 会硬扛

小病有概率先不去——余额越紧张越可能扛。这比「一生病就去医院」像人。

拖着不治，病情会升级：轻微不适 → 感冒 → 发烧 → 肠胃炎 → 阑尾炎。

## 给终端用的接口

| 方法 | 说明 |
|---|---|
| `status()` | 当前状态（会自动处理自愈） |
| `fall_sick(key)` | 让她生病，key 留空按常见病抽 |
| `quote()` | 报价：总费、医保报、自付 |
| `treat()` | 完整流程：报价 → 请终端扣款 → 治疗或放弃 |
| `worsen()` | 病情加重一档 |
| `heal()` | 直接治好（管理员用） |

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `sick_prob` | 0.02 | 基础生病概率（雨天 +0.03，低温 +0.02） |
| `auto_treat` | 是 | 生病后要不要自动去治 |
| `tough_it_out` | 是 | 小病先扛着 |
| `insurance_enable` | 是 | 关掉就全额自费 |
| `worsen_enable` | 是 | 不治会变重 |
